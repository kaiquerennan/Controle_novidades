Você receberá uma captura de tela real do ERP EMC.

Sua tarefa é editar exclusivamente a imagem recebida, preservando integralmente sua aparência original e alterando apenas informações sensíveis para que a imagem possa ser utilizada na documentação oficial das novidades do sistema.

## OBJETIVO

Anonimizar completamente dados reais ou identificáveis, mantendo a tela visualmente idêntica à original.

A imagem final deve parecer uma captura de tela real do ERP, e não uma imagem recriada.

----------------------------------------------------------------------
REGRAS OBRIGATÓRIAS
----------------------------------------------------------------------

1. PRESERVE A INTERFACE ORIGINAL

Não altere, recrie ou redesenhe:

- Layout
- Resolução
- Dimensões
- Proporções
- Cores
- Fontes
- Ícones
- Botões
- Menus
- Abas
- Campos
- Tabelas
- Grid
- Bordas
- Espaçamentos
- Alinhamentos
- Mensagens do sistema
- Estrutura da tela

A interface deve permanecer exatamente igual à imagem original.

----------------------------------------------------------------------

2. ALTERE SOMENTE OS DADOS IDENTIFICÁVEIS

Substitua apenas informações que possam identificar pessoas, empresas ou dados confidenciais.

Exemplos:

Clientes
- Cliente EMC 1
- Cliente EMC 2
- Cliente EMC 3

Fornecedores
- Fornecedor EMC 1
- Fornecedor EMC 2

Razão Social
- CLIENTE EMC 1 LTDA
- CLIENTE EMC COMÉRCIO LTDA
- EMPRESA DEMONSTRAÇÃO EMC

Endereços
- Rua das Flores
- Avenida EMC Sistemas
- Rua Exemplo
- Centro
- Belo Horizonte
- MG

Telefones
- (31) 3333-4444
- (31) 99999-8888

E-mails
- contato@clienteemc1.com.br
- financeiro@empresaemc.com.br

CNPJ
- 12.345.678/0001-90

Inscrição Estadual
- Utilizar valores fictícios.

CEP
- Utilizar CEP fictício.

Observações
- Substituir qualquer informação confidencial por textos fictícios coerentes.

----------------------------------------------------------------------

3. MANTENHA AS INFORMAÇÕES TÉCNICAS

Estas informações fazem parte da documentação e devem permanecer exatamente como estão:

- Código do Produto
- Código do Serviço
- CFOP
- CST
- NCM
- NBS
- IBS
- CBS
- Classificação Tributária
- Percentuais
- Alíquotas
- Valores técnicos
- Regras fiscais
- Campos tributários
- Fórmulas
- Demais informações técnicas do ERP

Caso exista dúvida entre um dado técnico e um dado identificável, preserve o dado técnico.

----------------------------------------------------------------------

4. NÃO MODIFIQUE A INTERFACE

É proibido:

- Redesenhar a tela
- Modernizar a interface
- Alterar cores
- Alterar fontes
- Alterar tamanhos
- Mover componentes
- Cortar a imagem
- Alterar resolução
- Adicionar novos elementos
- Remover elementos existentes
- Criar novos menus
- Criar novos botões
- Inventar funcionalidades

----------------------------------------------------------------------

5. NÃO UTILIZE EFEITOS VISUAIS

Não utilizar:

- Blur
- Desfoque
- Pixelização
- Tarjas
- Caixas
- Círculos
- Setas
- Destaques
- Marcadores
- Legendas
- Comentários
- Marca d'água

A alteração deve ser imperceptível.

----------------------------------------------------------------------

6. QUALIDADE DA EDIÇÃO

Os textos substituídos devem manter exatamente:

- Mesma fonte
- Mesmo tamanho
- Mesma cor
- Mesmo alinhamento
- Mesmo espaçamento
- Mesma quebra de linha
- Mesma aparência da captura original

A imagem final deve parecer uma captura autêntica do sistema.

----------------------------------------------------------------------

7. COERÊNCIA

Todas as informações substituídas devem permanecer coerentes entre si.

Exemplo:

Se o cliente for alterado para "Cliente EMC 1", todos os campos relacionados deverão utilizar esse mesmo nome.

Não utilizar nomes diferentes para representar o mesmo cadastro.

----------------------------------------------------------------------

8. IMPORTANTE

Esta é uma tarefa de EDIÇÃO DE IMAGEM, e não de geração de uma nova imagem.

Utilize obrigatoriamente a imagem recebida como base.

Preserve todos os pixels que não contenham informações sensíveis.

Altere somente as regiões estritamente necessárias para substituir os dados confidenciais.

----------------------------------------------------------------------

9. RESULTADO

Retorne exclusivamente a imagem final tratada.

Não forneça:

- Explicações
- Comentários
- Descrições
- Legendas
- Texto adicional

A saída deve conter apenas a imagem editada.
